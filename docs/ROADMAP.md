# Roadmap

Local AI Command Center v1.0-local establishes a rock-solid, local-first foundation for AI agent tracking.

## Future Local-First Ideas

1. **Enhanced Obsidian Integration**: Direct visualization of the markdown node graph within the Local AI UI without opening Obsidian.
2. **Local LLM Execution**: Integration with Ollama or LM Studio to replace cloud API keys entirely for low-tier tasks.
3. **Advanced Scheduler Telemetry**: Capturing historical execution time-drifts for Windows Scheduled Tasks.
4. **Offline Speech Synthesis**: Adding local Voice-to-Text inputs for Check-ins.

*Note: Local AI is strictly a local-first system. There are no plans for SaaS cloud deployments, managed remote databases, or public inbound webhooks.*
